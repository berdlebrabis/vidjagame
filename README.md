# Neon Wave V1

A small original neon wave arcade game built with HTML, CSS, and JavaScript. No dependencies or copied art.

## Run

Download or clone this repository, then open `index.html` in a modern browser. Keep `index.html`, `style.css`, and `script.js` together in the same folder. No server or installation required.

## Controls

- Hold **Space**, mouse button, or touch on the game area to move diagonally up.
- Release to move diagonally down.
- Press **R** or click **Restart** to start again.

Avoid the purple obstacles and top/bottom walls. Your score increases as you survive. Best score is stored locally when supported.
